# Ocean Notes Frontend

A lightweight React UI for a simple notes app with localStorage persistence, designed with the Ocean Professional theme.

- Create, edit, view, and delete notes
- Auto-save on change and manual Save button
- Local storage persistence and sample seed notes on first run
- Responsive layout with top nav, sidebar, and main content area

## Run

- npm install
- npm start
- Open http://localhost:3000

No environment variables or external services are required.
